# Aldric Paladin Trainer

A minimal top-down React Three Fiber game for learning a level 6 Oath of Vengeance Paladin's skills (D&D 2024), MOBA style.

- **Move:** right-click or left-click the floor, or use the arrow keys
- **Skills:** Q W E R · D F · A T G · 1–9 (hover a button to see its tooltip and range)
- **Space:** end turn (refreshes Action, Bonus Action and the one-slot-per-turn rule)

```bash
npm install
npm run dev
```

GitHub Actions (`.github/workflows/deploy-game.yml`) builds this folder and deploys it to GitHub Pages.
